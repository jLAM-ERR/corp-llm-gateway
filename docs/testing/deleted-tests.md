# Deleted-tests ledger

Every test node id a prune PR removes, or a helper-consolidation PR changes, gets one
row here, in the same PR. The gates are in [must-keep.md](must-keep.md); a row is the
semantic-equivalence note the check inventory asked for while the refactor ran. Task 10
retired the inventory, and this ledger is the permanent record of what it proved.

A row is complete only when all of these hold:

- the id is not in `tests/_manifests/must_keep/` (must-keep ids are never deleted,
  re-split or reduced to fewer parameter cases);
- the surviving test(s) have the same inputs, select the same production path in setup,
  apply the same predicates and selectors, expect the same outcomes, and carry the same
  negative checks and parameter cases;
- for a disputed replacement, the production line the deleted test targeted was
  hand-mutated and the survivor failed;
- the one exception to the survivor rule: a trivial test (no branch exercised, not a
  policy default — plan Task 7 item 3) may name `none — trivial (<reason>)` as survivor,
  with `n/a (no survivor; coverage equal: <module>)` as fault injection, when a branch
  coverage run of the module (`pytest --cov=corp_llm_gateway --cov-branch`) with and without
  the test drops no line or arc (plan rev 17; the coverage gate that checked this until
  Task 10 is retired, so the PR quotes the two reports);
- a deletable id is in no `must_keep/` file and so in no ledger: its only manifest changes
  are its own `negative_log_checks.json` sites, if it had any (`negative_logs --write`),
  and its `moves.json` entry if it was moved earlier (`moves --check` refuses a key that is
  no longer in the tree); and `scripts/test-gates.sh minimal|full` is green.

## How to fill a row

- **baseline outcome**: from `git show 8936dc6:tests/_manifests/expected_outcomes.<env>.json`
  (the last ledgers that held every test), or from the run's own ledger
  (`scripts/test-gates.sh <env> --out DIR` leaves it in `DIR/ledger.json`) for a test added
  since. The committed ledgers hold must-keep ids only, and a deletable id is never one.
- **the check it made**: its asserts, raises / fail sites, the helpers it calls that check
  something, its parametrize cases and fixtures, read from the test as it was. Rows before
  Task 10 quote the retired check inventory (`git show 8936dc6:tests/_manifests/baseline_checks/<dir>.json`).
- **semantic note**: one sentence per difference that is not a rename; "none" is a
  valid note only when the body is unchanged apart from renames.
- **fault injection**: `file:line` mutated, the survivor's failing assertion, and the
  revert.
